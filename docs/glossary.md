# Glosario

[Volver al índice](README.md)

| Término | Significado |
| --- | --- |
| BFT | Tolerancia a fallos bizantinos |
| Validador | Réplica que verifica propuestas y puede emitir votos |
| Líder | Réplica encargada de proponer en una vista |
| Vista | Época lógica del protocolo asociada a un líder |
| QC | Certificado de cuórum que acredita votos suficientes |
| `f` | Número máximo de validadores bizantinos tolerados |
| Seguridad | No confirmar decisiones incompatibles |
| Vivacidad | Continuar progresando bajo condiciones adecuadas |
| Pacemaker | Mecanismo para avanzar de vista tras esperas |
| `highQC` | QC más avanzado conocido por un nodo |
| `lockedQC` | Información de bloqueo para votar de forma segura |
| Commit | Confirmación de un bloque conforme a la regla aplicable |
| Equivocación | Envío de propuestas incompatibles por un actor |
| Custodia | Responsable actual de un lote farmacéutico |
