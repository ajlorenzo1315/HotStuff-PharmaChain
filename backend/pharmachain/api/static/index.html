Cómo se alcanza el consenso

Guía paso a paso
01 · PROPOSE

El líder presenta un bloque que extiende una rama justificada.

02 · VOTE

Los validadores comprueban las reglas y firman un voto si es seguro.

03 · QC

Al reunir 3 votos válidos se forma un certificado de cuórum.

04 · COMMIT

En Chained HotStuff una cadena de tres bloques certificados permite confirmar un ancestro bajo las reglas de vistas y bloqueo.

Un QC no significa que ese mismo bloque ya esté confirmado. Las reglas de confirmación requieren una cadena certificada apropiada.
